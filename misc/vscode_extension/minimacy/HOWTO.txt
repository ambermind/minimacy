How to update keywords list
---------------------------------

Update keywords in file:
	syntaxes\minimacy.tmLanguage

This is a TextMate grammar in XML (plist) format.
Language keywords (if, then, let, ...) are in: repository > keywords > patterns > match
Bios keywords are in: repository > api > patterns > match

These lists are regular expressions in extended mode (they start with "(?x)"):
spaces and line breaks are ignored, so there is one keyword per line, each one
preceded by a pipe |, for example:

	<string>(?x)(?&lt;!\w)(
	  arrayDump
	| void
	| \\int
	)\b</string>

Rules:
- a keyword must not contain spaces nor '#' (in extended mode, '#' starts a comment)
- a backslash is written \\ (example: \\int for the keyword \int)
- XML escaping: < is written &lt;  > is written &gt;  & is written &amp;


How to build the extension
----------------------------------
In order to install or update vsce: npm install -g @vscode/vsce

The version number is in package.json ("version" field).
Change it before each new release.

Start the following command from directory minimacy\misc\vscode_extension\minimacy:

	vsce package          -> build with the current version

The build package is: minimacy-<version>.vsix (for example minimacy-2.1.6.vsix)


How to install the extension
----------------------------------
There is no need to remove the previous version: installing a newer version replaces it.

Either from VS Code: Extensions panel, "..." menu, "Install from VSIX..."
Or from the command line:

	code --install-extension minimacy-<version>.vsix

To reinstall the same version, add --force to the command line.

Then reload VS Code: Ctrl+Shift+P, "Developer: Reload Window".
